## 4. Checks that were actually run (script `07_validate_extraction.py`)

All 21 checks passed on the final outputs: JSONL parses; required fields present; unique IDs; no empty sections; exactly the 6 configured documents; no excluded documents; one company/source file per document; page ranges valid; every L2 has an L1 parent in the same document whose page range contains it; document_type matches the configured part; AXIOM abridged/RHP page confinement; no labels assigned; **L2 raw text equals L1 raw text exactly**; **independent non-whitespace character conservation** (sum of L1 sections = sum of page text, and L2 + contents page = page text, per document); every PDF page is in some L1; no TOC listing leaked into body chapters; every TOC entry resolved to a body location.

Limits of these checks: conservation proves no text was dropped or duplicated; it does **not** prove boundaries are semantically right. Two boundary bugs (below) passed conservation and were found only by the TOC-leak / size checks.

## 5. Extraction problems — confirmed

1. **Quanto: scanned restated financial statements (F-1 to F-36, pdf 236–271).** pdf 236–241 are image-only (text layer holds only the page label); pdf 242–271 (30 pages) are full-page images with an embedded OCR text layer showing OCR-typical errors (e.g. 'LIMITHD', 'Pormerly', '3O6927'). Fresh Tesseract OCR agrees with the embedded layer on a mean 0.854 of tokens (min 0.592, max 0.963), and OCR mean word confidence is 77.7. **Financial figures in this block cannot be trusted from either source without checking the page images.** The block is its own L1 (`quanto_agroworld-L1-027`, 165,018 chars) flagged `scanned_insert_F1_to_F36`.
2. **Image-only photo pages with unusable OCR:** Maxwell pdf 173 (conf 32.7), Quanto pdf 162, 163 (conf 35.3 / 30.9). OCR output is noise; ignore it.
3. **Image-only pages with usable text:** Maxwell pdf 2, 4 ('This page is intentionally left blank'), Photonics pdf 223 (divider/index page, 94% agreement with its text layer), Photonics pdf 157 (flowchart image), Quanto pdf 299. OCR text is stored separately in `ocr/` and is **not** merged into section text.
4. **Ideas pdf 121–123:** private-use glyph U+F0D8 (Wingdings arrow bullet) in extracted text. Raw kept; normalisation choice deferred to Phase 4.
5. **Source inconsistency:** Quanto TOC lists 'Capital Structure' on p.63, body heading is on printed p.64 (p.63 is a 'left blank' page).
6. **Quanto manual structure override (documented in `doc_config.json`):** TOC lacks the restated-financials insert, so `Capitalization Statement` (TOC p.231 → pdf 235 is only a divider/index page) was split into: divider page (pdf 235), the scanned insert (pdf 236–271), and the capitalization table (pdf 272). Headings come from the document's own index text; no text was invented.
7. **Page numbers:** printed page numbers recovered on 295–337 of ~300–390 pages per document; each document has an offset jump where the restated financial statements are inserted (e.g. pdf−printed ≈ 4 → 51 in Photonics). `start_page`/`end_page` are always the physical PDF page; printed page is a secondary field and may be null.
8. **No ligature, CID, mojibake, U+FFFD or control-character problems** were found in any document's text layer (measured counts are in `extraction_stats.json`).

## 7. Defects found in my own build and fixed (for transparency)

1. TOC parser merged Roman-numeral part headers ('I. GENERAL') into the next entry's title → 27 unresolved anchors in Century/Ideas and chapters swallowing 50+ pages. Fixed; 0 unresolved now.
2. First body chapter anchored on the TOC's own listing line (Century, Photonics, Ideas) → TOC text leaked into 'Definitions'. Found because contents-page sizes were implausible (46 chars). Fixed; leak check added.
3. Quanto 'SECTION I – GENERAL DEFINITIONS AND ABBREVIATIONS' was treated as a divider → Definitions chapter lost. Fixed with a rule (part followed by entry on a later page owns content).
4. Early L2 over-segmentation (1,000–1,700 per document) from bold table headers/fragments/signature lines → tightened rules; L2 now 777–1,104 per document.
5. A background OCR job was killed by a tool timeout and its partial results lost; re-run in resumable chunks. All 44 flagged pages were OCR'd.
